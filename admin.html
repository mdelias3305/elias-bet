⚙️ Admin Dashboard

Create, edit, enable/disable and delete games.

🔎

➕ Game Builder

Game type বেছে নিয়ে Add Game চাপলেই নতুন playable game card তৈরি হবে। Gallery থেকে custom icon-ও দিতে পারবেন।

📦 Game Import

নিজের HTML game file upload করে sandbox preview হিসেবে game যোগ করুন, অথবা একটি game URL দিন।

🎮 Manage Games

Search by game name, type, description or status.

🔎

📱 Deposit Number Settings

এখানে Admin থেকে deposit display number পরিবর্তন করতে পারবেন। এটি কোনো cash payment gateway/transfer চালু করে না।

📤 Withdraw Number Settings

Admin থেকে withdraw display number সেট করতে পারবেন। এটি কোনো cash payment gateway/transfer চালু করে না।

✅ Deposit Transactions — Admin Approval

Customer deposit করলে এখানে Pending থাকবে। Done/Approved করলে তবেই balance-এ amount যোগ হবে। Reject করলে balance বাড়বে না।
